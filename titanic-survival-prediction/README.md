# Titanic Survival Prediction 🚢

Predict survival on the Titanic using machine learning. This project demonstrates feature engineering, model comparison, and comprehensive data analysis.

## 📊 Dataset
- **Source**: Kaggle Titanic Competition
- **Training samples**: 916 passengers
- **Validation samples**: 197 passengers
- **Test samples**: 196 passengers
- **Features**: 7 original + 3 engineered features

## 🧠 Models Implemented
- Random Forest - **Best Performance**
- Gradient Boosting
- Logistic Regression  
- K-Nearest Neighbors
- Support Vector Machine

## 🔧 Key Skills Demonstrated
- Feature Engineering (Family size, Age groups)
- Handling Missing Values
- Model Comparison and Hyperparameter Tuning
- Permutation Feature Importance
- Comprehensive Data Visualization

## 📈 Results
- **Best Model**: Random Forest
- **Validation Accuracy**: 77.66%
- **Key Features**: Gender, Passenger Class, Parch

## 🎯 Key Insights
- Women had a significantly higher survival rate when compared to men
- First class passengers had a much higher survival rate when compared to third class
- "Women and children first" protocol clearly visible in data
