# Iris Flower Classification 🌸

A machine learning project that classifies iris flowers into three species based on their sepal and petal measurements.

## Project Overview
- **Problem Type**: Multi-class Classification
- **Models Tested**: Logistic Regression, K-NN, SVM, Decision Tree, Random Forest
- **Best Accuracy**: 100%
- **Dataset**: sklearn's built-in Iris dataset

## Dataset Features
- Sepal length (cm)
- Sepal width (cm) 
- Petal length (cm)
- Petal width (cm)

## Target Classes
- 0: Iris Setosa
- 1: Iris Versicolor  
- 2: Iris Virginica

## Project Structure
- Data Exploration & Visualization
- Data Preprocessing
- Model Training & Evaluation
- Performance Comparison
- Prediction Examples

## Technologies Used
- Python
- scikit-learn
- pandas, numpy
- matplotlib, seaborn

The KNN classifier achieved the highest accuracy of 100% on the test set.
