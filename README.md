# Simple-ML-projects
Simple Machine Learning Projects | Classification | Regression | NLP | Computer Vision | Beginner-friendly implementations of ML algorithms with scikit-learn, TensorFlow, and Keras.

## 📁 Projects

### 1. Iris Flower Classification
- **Problem Statement**: Multi-class classification of iris species using petal/sepal measurements
- **Algorithms Tested**: KNN, Logistic Regression, Random Forest, SVM
- **Key Skills**: Data visualization, model comparison, feature importance
- **Results**: 100% accuracy with KNN

### 2. Titanic Survival Prediction
- **Problem Statement**: Binary classification of which passengers survived the titanic and report key findings 
- **Algorithms Tested**: Random Forest, Gradient Boosting, Logistic Regression, KNN, SVM
- **Key Skills**: Data visualization, model comparison, feature importance
- **Results**: Random Forest gives best accuracy and women and children first protocol can be seen.
